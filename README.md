# B站关注清理助手（第一版）

这是一个仅在本机浏览器中运行的 Chrome / Edge 扩展。它会读取当前已登录账号的关注列表，为每个 UP 主读取最近一条普通视频，并按设定规则生成候选名单；只有在结果页勾选并二次确认后，才会逐项尝试取关。

默认规则为：

- 最近一条可识别普通视频距今至少 **30 天**；或
- 最近一条视频的播放量低于 **1000**，且视频至少发布满 **7 天**。

“满足任一条件”是默认逻辑。播放量观察期是为了避免刚发布的视频因数据尚未积累而被误判；可以在弹窗中调整为 0。

## 安装

1. 打开 Chrome 或 Edge 的扩展管理页：Chrome 为 `chrome://extensions`，Edge 为 `edge://extensions`。
2. 开启右上角的“开发者模式”。
3. 点击“加载已解压的扩展”。
4. 选择本文件夹：`C:\Users\ce123\Desktop\边城\一键取关`。
5. 打开任意 B 站网页并手动登录，点击浏览器工具栏里的“B站关注清理助手”。

## 使用

1. 保持默认的 N=30、X=1000，点击“开始扫描”。
2. 扫描页会逐项显示最近视频、发布日期、播放量和命中理由。先抽查若干条链接确认数据准确。
3. 默认会勾选候选项。取消不想取关的账号；可以搜索、筛选和导出 CSV。
4. 点击“取关已勾选项”，阅读第一次确认提示，再按要求输入确认文字。
5. 结果页保留本次的成功、失败和未操作状态；失败项不会被静默重试。

## 数据与边界

- 数据和扫描结果存储在浏览器本机扩展存储中，不会发送到第三方服务器。
- 扩展不会保存密码或 Cookie。取关时只会临时从已打开的 B 站页面读取网页本身使用的 CSRF 令牌，随后立即用于该次请求，不写入本地存储。
- 扫描依赖 B 站网页当前的数据服务和返回格式。页面、登录策略或接口变化后可能失效，出现“读取失败”时应先停止操作并人工核验。
- 第一版只识别最近一条普通投稿视频；无可识别视频、读取失败或数据异常的账号不会自动进入候选名单。
- 建议首次只取关少量已人工核对的账号。取关可手动重新关注，但工具无法自动恢复原关注状态。
