# 关注清理助手

用于整理本人关注列表的 Chrome / Edge 本地扩展。名单导出为两列 TXT，每行包含名称和平台标识，以制表符分隔。头像比对在本机进行，无需 AI API。

| 平台 | 名单与筛选 | 取关 |
|---|---|---|
| 哔哩哔哩 | 按页采集名称和 UID，可只导出名单，也可读取作品数量、最近三条作品播放量和发布时间 | 复核并勾选后执行，显示逐项结果、速度与预计剩余时间，可暂停或停止 |
| 抖音、快手（实验） | 用户指定关注列表区域，滚动加载后收集主页链接和头像。导出的主页标识与展示账号号可能不同，名单按部分结果标记 | 人工复核后在平台页面操作 |

## 安装

1. 下载并解压仓库，或将仓库克隆到自选文件夹。
2. 打开 `chrome://extensions` 或 `edge://extensions`，开启开发者模式，点击「加载已解压的扩展」。
3. 选择含有 `manifest.json` 的文件夹。扩展更新后，在扩展管理页点击重新加载，并刷新平台网页。

## 使用

- 仅需名单时，在弹窗中选择平台及名单采集入口。B 站采集结果会标注人数是否与平台返回的总数一致。
- 如果想找到使用特定头像的账号，请提供该平台的参考头像，核对候选人的名称、主页和头像，再手动勾选。头像一致只表示图片匹配。注销、禁言和限制投稿均需独立的平台证据。
- B 站的作品筛选默认使用 30 天未投稿或最近作品播放量低于 1000 的条件，低播放量条件默认有 7 天观察期。可在管理页编辑或导入 JSON 规则，示例见 [rules.json](rules.json)。缺少的播放量按未知处理。
- B 站执行取关时保持管理页打开。平台拒绝或结果无法确认时，队列停止，可查看各账号状态。

## 验证范围

仓库提供离线规则与队列测试。网页结构和登录状态会影响实际可用性，三平台的真实账号流程尚未完成端到端验收。
