# 关注清理助手

在自己的关注页面点击浏览器工具栏中的扩展图标，网页旁会打开独立侧栏。不需要选择平台，不会跳转到 B 站。需要支持扩展侧栏的桌面版 Edge 或 Chrome，侧栏位置由浏览器设置决定。

## 安装与使用

1. 下载仓库并解压，在浏览器扩展管理页打开开发者模式，加载含有 `manifest.json` 的文件夹。已有旧版请点击「重新加载」并刷新平台网页。
2. 登录平台，进入「我的关注」。B 站使用个人空间「关注数 → 全部关注」；抖音使用「关注」页面并展开用户列表；快手需打开可识别的关注列表。
3. 点击扩展图标，设置条件（默认 30 天未投稿或最近一条播放低于 1000），或导入 [JSON 规则示例](rules.json)。第一次确认只读取名单。缺失数据不当作零，近三条平均需要三条都有对应指标。
4. 候选逐行显示 ID 和命中原因，默认不选。逐个点击标红，可撤销；也可导出两列 TXT（名称、平台主页 ID）。名单未核实完整时会明确提示。
5. 复核标红人数后点击最终确认，保持侧栏和目标标签页打开。队列逐项更新结果、速度和预计时间，可暂停或停止。停止无法撤回已发出的请求；失败或状态不确定时停止，不自动重试。切换标签页或导航会清除当前复核。不要用批量操作测试平台限制；操作间隔不保证账号安全。

## 实际支持范围

| 平台 | 数据与限制 | 取关条件 |
|---|---|---|
| 哔哩哔哩 | 核对登录 UID 后按页读取名单；按规则补查最近普通视频投稿、播放、评论、粉丝数。普通视频投稿数不是所有类型的动态总数。分页中断保留部分结果。 | 提交前检查登录身份和关系，提交后再次读取关系确认 |
| 抖音、快手（实验） | 只读取能识别的关注列表，不从推荐流收集账号。尝试滚动列表并按主页标识去重。按需从与标识严格匹配的资料补充作品数和粉丝数；网页未提供的作品时间、近三条数据等为未知。主页标识未必等于展示账号号。 | 仅在能绑定登录身份、页面及原名单，并在目标行找到唯一关系按钮时操作。列表行未加载、弹出独立确认框或状态不明时不再继续，需要人工核对。 |

头像按完整 URL 比对，仅说明地址一致，不证明被封禁。账号状态仅采信已识别的独立状态标记，不从昵称、头像或零作品推断。网页改版、权限与登录状态均可能影响结果。当前有离线测试，未用三个平台的真实账号验证批量取关；不承诺可读完整万人名单。

关注名单和复核状态只在当前侧栏会话使用，不上传到 GitHub 或 AI 服务。发布仓库不包含个人导出、登录信息或本机安装路径。
